Smart Campus Navigation and Facility Analytics System

Authors:
  Robert Clark
  Wesley Jackson
  Tia Davis

System to locate facilities, explore building connections, find routes, browse a department hierarchy, and view summary reports for a campus.

File Organization:
include/ has all header files.
src/ has all source files.
data/contains the input files.
testdata/ contains testfiles and their results

cmd to run: g++ -Iinclude src/main.cpp src/Hashtable.cpp src/Facility.cpp src/department.cpp src/CampusGraph.cpp
